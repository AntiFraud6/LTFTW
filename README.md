## 0. AntiGenerate – Dialogue Generation

- Set API for **Gemini / DouBao / GPT** (all named `Gemini` internally; the underlying model has been swapped)

## 2. R1CoTGenerate – Dialogue Annotation

🏷️ **Purpose**: Use a model to perform sequence labeling on generated dialogues.

### ⚙️ Configuration

- `config/settings.py`: Set **DeepSeek (slow-thinking)** API
- `utils/block_processor.py`: Set `BlockSize` 
  *(Experiments default: `BlockSize=10`; sensitivity analysis uses `5` and `15`)*

### 🚀 Run `main.py`

- Set `input_dir`: JSONL files of scam dialogues processed by **DataProcess**  
- Set `output_dir`: output directory for annotations (CSV)
- Concurrency control: adjust `asyncio.run(main(max_concurrent_files=x))` according to your machine.

---

## 3. Trian – Model Training

🏋️ **Purpose**: Fine-tune the model on annotated data.

### ⚙️ Configuration `config/settings.py`

- `MODEL_NAME`: path to the base model (usually a local path)
- `CHECKPOINT_PATH`: if empty, use the base model directly; otherwise, it is **base + first‑stage checkpoint** (i.e., continue fine‑tuning from stage 1)
- `DATA_PATH`: training data path (dataset provided)
- `OUTPUT_DIR`: checkpoint output path
- `VAL_DATA_PATH`: validation data path (used for early stopping; dataset provided)

🚀 **Run command**:

```bash
torchrun --nproc_per_node=4 --master_port=29500 train.py
```

## 6. F1Compute – Metric Calculation

📈 Compute evaluation metrics from the Pred information (e.g., $L_f$) obtained in step 4.

### 6.1 RTCompute

🔢 Calculate R and T values from the raw model‑returned CSV.

- `source_directory`: original CSV directory (usually `4.PredDanger\0.InitialData`)
- `target_directory`: output directory (usually `4.PredDanger\1.ProcessedData`)

---

### 6.2 HighDangerLabel

🚨 Assign high‑danger labels based on the R and T values from the previous step, according to defined rules.

- `input_dir`: `4.PredDanger\1.ProcessedData` (contains R, T)
- `output_dir`: `4.PredDanger\2.LabelData` (output with labels)

---

### 6.3 ComputeF1csvFile

📋 Generate a CSV file for computing F1, FPR, MLLT, MAWO (pred and true aligned one‑to‑one).

- `csv_dir`: Pred CSV with labels from the previous step (`4.PredDanger\2.LabelData`)
- `jsonl_dir`: ground‑truth JSONL files with labels (provided data, located in `3.TrueDanger`)
- `output_dir`: final output directory (`4.PredDanger\3.Finally`)

---

### 6.4 Metrics / Metrics2

📊 Compute final metrics from the aligned CSV:

- **Metrics** → calculates MLLT
- **Metrics2** → calculates MAWO

---

## 7. SensitivityAnalysis – Sensitivity Analysis

🔬 Analyze the impact of hyperparameters $\varepsilon$ and $R_{th}$.

### (0) ComputeRT

Convert raw CSV (original DeepSeek-Reasoner output) to JSONL and **re‑compute R and T recursively** (without relying on previous `prev_R`, `prev_T`).

- Set `INPUT_DIR` to the original DeepSeek annotation output.

---

### (1) AddStage

Add the `stage` field to the newly generated JSONL for subsequent median R/T statistics.

- `dir_a`: JSONL files with R and T from step (0)
- `dir_b`: previously existing JSONL files that already contain `stage` labels

Maps the `stage` from `dir_b` onto `dir_a` (structure is identical).

---

### (2) jsonl2csv

Consolidate JSONL files into one CSV recording all R and T values.

- Set `dir_path` to the JSONL directory produced by step (1).

---

### (3) TthRincth

Calculate thresholds $R_{th}$ ($T_{th}$) etc.

- `df = pd.read_csv("/1.Statistics.csv")` 
  *(the CSV file from step (2))*
- Output the thresholds to `output_path` (e.g., `xxx\result.txt`).

After this, go through the **6. F1Compute** pipeline to obtain final metrics.
